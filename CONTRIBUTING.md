# Участие в разработке KVN

Используйте GitHub Issues для описания ошибок и предложений. Для исправлений создавайте pull request, привязанный к задаче.

Перед отправкой изменений:

1. Проверьте сборку, тесты и совместимость с актуальной основной веткой.
2. Не добавляйте пароли, адреса собственных серверов, ключи подписи, токены или личные данные пользователей в исходники, скриншоты и логи.
3. Для сетевых изменений опишите воспроизводимый сценарий, реальное устройство/версию ОС, критерии проверки и влияние на DNS, IPv4/IPv6, UDP, маршруты и отсутствие прямых утечек.
4. Сохраняйте авторские уведомления и лицензии сторонних компонентов. Для существенных заимствований указывайте источник и лицензию.
5. Не объявляйте успешную сборку подтверждением работоспособности VPN на реальном устройстве.

Принцип проекта: простой интерфейс, проверяемое поведение, минимальное количество скрытых допущений. Реализация Windows развивается отдельно от Android.
