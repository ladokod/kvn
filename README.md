# KVN — минималистичный VPN-клиент

**KVN** — открытый Android-клиент для собственного сервера NaïveProxy (HTTPS / Caddy). Один экран, одна кнопка, три поля настройки: адрес сервера, логин и пароль.

Это независимый проект Ladokod, неофициальная адаптация сетевой инфраструктуры [Husi](https://github.com/xchacha20-poly1305/husi) и [sing-box](https://github.com/SagerNet/sing-box). Проект не связан с авторами Husi и sing-box.

## Android

Версия **0.2.0**: Android 8.0 и выше; основная архитектура — **ARM64**. Реальные подключения проверялись на Android 16. Поддержка других устройств и сетей требует дальнейших испытаний.

После официального выпуска APK, контрольные суммы и соответствующие исходники появятся на [странице релизов](https://github.com/ladokod/kvn/releases). **Не устанавливайте произвольные APK из чужих источников.**

Для подключения укажите домен своего сервера NaïveProxy, логин и пароль. Нужен совместимый сервер; KVN не предоставляет общедоступные серверы или подписки.

## Сборка из исходников

Требуются Go 1.27.0, JDK 17, Android SDK 35, Android NDK 29.0.14206865, Gradle 8.13 и Python 3.12. Точные команды и зависимости приведены в [технической документации](docs/HUSI-MIGRATION-RU.md). Для использования APK требуется стабильный ключ подписи; тестовая сборка, подписанная другим ключом, не заменяет уже установленное приложение без переустановки.

Трафик проходит через настроенный пользователем сервер. Секреты профиля сохраняются локально с помощью Android Keystore. При ошибке прокси приложение не должно переключать пользовательский трафик на прямое соединение.
