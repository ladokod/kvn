KVN переходит на сетевое ядро и Android API Husi v2.3.4. Интерфейс остаётся KVN: одна кнопка, состояние и три поля настроек. Сервер NaïveProxy + Caddy менять не нужно.

- Встроенный Naïve/Cronet, Go TCP stack, FakeDNS, согласованные IPv4/IPv6 маршруты и MTU.
- Проверка HTTPS отделена от создания TUN; ошибка проверки из процесса VPN не отключает пользовательский трафик.
- Пароль зашифрован Android Keystore. Direct fallback и UDP-over-TCP выключены.
- Пользователь подтвердил работу новой сборки на своём физическом телефоне.
- CI проверяет собственный core, JVM-тесты и реальный TUN на эмуляторе Android 16: большие/параллельные HTTPS, DNS, IPv4/IPv6, TLS hostname, UDP reject, остановку/переподключение и неверный пароль.

**Установка:** скачать `KVN-0.2.0-arm64.apk`. Android ARM64, версия Android 8.0 и выше. Ввести домен сервера, логин и пароль; порт и TLS заданы автоматически.

APK не содержит тестового CA или реквизитов CI-стенда. Он использует временный CI-ключ подписи; при конфликте подписи с предыдущим APK потребуется удалить старую сборку, что удалит сохранённый профиль. Постоянная production-подпись пока не настроена.

В `KVN-0.2.0-sources-and-notices.tar.gz` находятся соответствующие исходники KVN, зафиксированных Go-компонентов и нативного NaiveProxy/Chromium, лицензии и уведомления. `SHA256SUMS` содержит контрольные суммы. KVN — независимый проект под GPL-3.0-or-later, без официальной связи с авторами Husi.

Подробности: [технический отчёт](https://github.com/ladokod/kvn/blob/v0.2.0/docs/HUSI-MIGRATION-RU.md), [проверка на телефоне](https://github.com/ladokod/kvn/blob/v0.2.0/docs/PHONE-TEST-RU.md).
